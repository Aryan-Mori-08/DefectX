# Reference Images Directory

Place defect-free reference images (10-30 images) in subdirectories by product_id.

## Structure:
```
data/reference/
└── <your_product_name>/
    ├── 001.png
    ├── 002.png
    ├── 003.png
    └── ...
```

## Example:
```
data/reference/my_product/001.png
data/reference/my_product/002.png
...
```

## Guidelines:
- Use 10-30 high-quality defect-free images
- Images should represent normal product variations
- Ensure consistent lighting and camera angle
- Images will be used to build the memory bank for anomaly detection
